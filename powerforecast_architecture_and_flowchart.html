Server-Dependent Data Tier

1. Server-Dependent Database & ETL Pipeline Architecture

The **DOE PELP Appliance Database is strictly server-dependent**. The client browser never downloads the heavy 5MB+ registry. Instead, the server parses official DOE bulletins, caches 6,819 indexed models across 6 categories, and handles real-time multi-token search and pagination over lightweight REST endpoints.

    }

    HOUSEHOLD_LOAD_ITEM {
        int id PK "Timestamp Identifier"
        string user_id FK "User Account Reference"

    %% Entry & Authentication
    START(["Start / Access PowerForecast"]):::authNode --> AuthChoice{"User Authenticated?"}:::decisionNode

    LoginMethod -->|"New User"| RegForm["Sign Up Registration (Name, Email, Password)"]:::authNode
