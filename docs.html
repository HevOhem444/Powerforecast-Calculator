Public Meralco Rate & Calculation API

The PowerForecast API allows developers to fetch parsed Meralco rate schedules, query common household appliance wattage metrics, and perform precise, itemized bill calculations. Hosted on Vercel Serverless Functions with CORS enabled.

Base URL: https://powerforecast-api.vercel.app
GET

/api/rates

Retrieves the latest parsed Meralco residential rate brackets, generation charges, and rate trends.

fetch('https://billshock-api.vercel.app/api/rates')
  .then(res => res.json())
  .then(data => console.log(data));
GET

/api/appliances

Returns typical Philippine household appliance wattage standards, operational ranges, and default daily usage hours.

fetch('https://billshock-api.vercel.app/api/appliances')
  .then(res => res.json())
  .then(data => console.log(data));
POST / GET

/api/calculate

Calculates a fully itemized Meralco bill based on consumption metrics.

fetch('https://billshock-api.vercel.app/api/calculate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    kwh: 300,
    generation_rate: 9.2504,
    other_charges: 0.00
  })
})
  .then(res => res.json())
  .then(data => console.log(data));
