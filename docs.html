Public Meralco Rate & Bill Calculation API

The PowerForecast REST API provides real-time access to parsed Philippine Meralco rate bulletins, household appliance wattage standards, and precision itemized bill calculation formulas.

Base URL: https://powerforecast-api.vercel.app
GET

/api/rates

Content-Type: application/json

Fetches the latest effective residential rate schedule per consumption tier, including generation charges, distribution brackets, transmission fees, and tax ratios. 

fetch('https://powerforecast-api.vercel.app/api/rates')
  .then(res => res.json())
  .then(data => console.log(data));
GET

/api/appliances

Content-Type: application/json

Returns standard wattage specifications, hourly consumption rates, and operational power ranges for common Philippine household appliances. 

fetch('https://powerforecast-api.vercel.app/api/appliances')
  .then(res => res.json())
  .then(data => console.log(data));
POST

/api/calculate

Content-Type: application/json

Calculates a complete, itemized Meralco electric bill given monthly energy consumption in kilowatt-hours (kWh) and base generation rate.

Field Type Required Description
kwh number Yes Monthly consumption in kilowatt-hours (e.g. 300)
generation_rate number Optional Base generation charge per kWh (Default: 9.2504)
other_charges number Optional Flat fee or additional municipal adjustments (Default: 0.00) 
fetch('https://powerforecast-api.vercel.app/api/calculate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    kwh: 300,
    generation_rate: 9.2504,
    other_charges: 0.00
  })
})
  .then(res => res.json())
  .then(data => console.log(data));
